# El Refugio de Om

Bilingual Spanish/English website with life coaching and biodecoding service details, Google Calendar booking, contact links and Homesick/A Page a Day app links.

## Publish with GitHub Pages

In Settings → Pages, select Deploy from a branch, main and / (root). No installation or build is required.

The contact form prepares a draft in the visitor’s email application. It does not submit or store messages.
